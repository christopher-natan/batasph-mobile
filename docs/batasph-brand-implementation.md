# Selected identity artwork

User selection: 03 / A clearer balance, from `batasph-logo-concepts.png`.

The transparent master was generated with the imagegen tool using the comparison board as its reference. Exact prompt:

Create a production logo master for BatasPH from ONLY option 03 'A clearer balance' in the provided comparison board. The input is a design reference. Output only the standalone emblem, no words, no label, no board, no tile, no background, on a genuinely transparent alpha background. Faithfully reproduce option 03's geometry: a small circular amber sun #C8964F floating above a central pillar; a horizontal rounded balance beam; two symmetric suspended scale bowls; at the bottom two broad gracefully curved open-book pages meeting at the center below the pillar. Deep forest green #1F4D3F for all shapes except the amber sun. Preserve the tasteful curved beam-to-pillar connection and the clean negative spaces in the triangular scale suspensions. Flat solid fills, perfect bilateral symmetry, smooth clean edges, no texture, no shading, no shadows, no extra strokes, no gradients. Make the symbol large centered on a square canvas with modest even transparent margins (about 10 percent), all parts visible. This is for a real app identity, must be extremely crisp, simple and identical in spirit and silhouette to concept 03. Do not include anything from concepts 01 or 02.

The launcher master was generated from that mark as an ivory emblem with an amber sun on a solid forest-green square. Transparent inverse attempts with visible speckles were rejected. Production masters are stored in `assets/branding/`; `tools/export_branding.ps1` resizes and packages them. No live API key is needed to re-export.

See `assets/branding/README.md` for the complete asset list and `docs/design-previews/` for implemented screens. The two masters are separately generated raster treatments; they are not an editable vector logo system.
